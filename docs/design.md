# PinPaste 设计系统文档

> 从 v0.3.0 视觉重构到 v0.4.0 卡片网格布局，记录设计决策、令牌体系与组件规范。

## 设计原则

1. **克制** — 少量精色，大面积留白。不做无意义的装饰。
2. **层次** — 用色彩明度和间距区分层级，不用粗边框。
3. **柔和** — 圆角 10-14px，阴影柔和不刺眼。
4. **节奏** — 8px 基础网格，间距有呼吸感。
5. **动效** — 150-220ms ease-out，自然不突兀。

## 设计令牌

所有视觉属性通过 CSS 变量管理，支持亮色/暗色双主题。

## 组件规范

### 列表项

**单列模式（默认）**

- 固定 64px 高，横向排列
- 上行：内容文本（单行省略号）
- 下行：`时间 · 来源`（meta 行，11px 次要文字色）
- 右侧：收藏按钮（36px 宽，分隔线）

**卡片模式（窗口 ≥780px）**

- 自适应高度，最小 100px
- 3/4/5 列网格（780/1100/1420px 断点）
- 内容最多 4 行（`-webkit-line-clamp: 4`）
- 收藏按钮移至右上角绝对定位，hover 显示
- 图片缩略图放大到 56px

### 搜索框

- 聚焦时有靛蓝色光晕（`box-shadow` + `accent-bg`）
- 实时搜索，无需按钮触发

### 设置面板

- iOS 风格 segmented 控件（主题、语言切换）
- 毛玻璃遮罩层（`backdrop-filter: blur(8px)`）
- 弹窗入场动画（`translateY(8px) → 0` + opacity）

### 编辑弹窗

- 480px 宽，居中显示
- 毛玻璃遮罩层
- 文本内容用 `<textarea>` 可编辑，图片只读
- 底部保存/删除按钮

### 侧边栏

- 120px 宽，靛蓝色高亮选中项
- 「当前 · App名」格式显示当前活跃 App
- Tab 切换：自动剪切 / 收藏

### 滚动条

- 8px 宽，圆角，半透明
- hover 时加深
- Firefox 用 `scrollbar-width: thin` 原生适配

## 国际化

- 自建轻量 i18n 方案，无第三方依赖
- 字典结构：`Record<string, [zh, en]>`，通过索引切换语言
- 60+ 翻译条目，覆盖所有 UI 文本
- `useLang` hook 管理：localStorage 持久化 + 浏览器语言自动检测
- 后端 `settings` 表新增 `lang` 字段同步持久化

## 响应式策略

使用 `@media` query 实现窗口宽度自适应（非 Container Query）：

> **设计决策记录**：最初尝试使用 CSS Container Query（`container-type: inline-size`），
> 但发现容器查询无法改变容器自身的 `flex-direction`，只能影响后代元素。
> 后改为 `@media` query，断点偏移 +140px 补偿 sidebar(120px) + padding。

| 窗口宽度 | 布局     | 列数 |
| -------- | -------- | ---- |
| <780px   | 单列列表 | 1    |
| ≥780px   | 卡片网格 | 3    |
| ≥1100px  | 卡片网格 | 4    |
| ≥1420px  | 卡片网格 | 5    |

## 主题切换

- 三态：跟随系统 / 浅色 / 深色
- 通过 `data-theme` 属性切换 CSS 变量集
- 系统模式监听 `prefers-color-scheme` 自动切换

## 踩坑记录

### Container Query 不能样式化容器自身

**问题**：在 `.list` 上设 `container-type: inline-size`，然后用 `@container (min-width: 640px) { .list { ... } }` 改 `.list` 自身的 `flex-direction`——不生效。

**原因**：Container Query 只能匹配容器**内部**的后代元素，不能匹配容器自身。

**解决**：改用 `@media` query，断点 +140px 补偿 sidebar 宽度。

### blur 事件导致窗口隐藏

**问题**：点击置顶按钮后窗口消失，无法唤出。

**原因**：`show → focus → blur` 序列中，blur 监听触发 `hideMainWindow`。

**解决**：

1. 移除 `show_main` 中的 `set_always_on_top` 调用
2. blur 监听加 300ms guard（`lastShowTime` 检查）
3. `pinnedRef` 拦截 blur 事件

### Tab 切换卡顿

**问题**：切换 Tab 时明显延迟。

**原因**：`refresh` 函数串行 3 个后端请求，其中第二个 `getItems` 拉全部条目仅为提取 app_source 列表。

**解决**：

1. 用 `Promise.all` 并行化请求
2. 用轻量 `getAppSources()`（SQL DISTINCT）替代拉全部条目再前端提取

### Tauri 命令在主线程阻塞

**问题**：大量 App 图标请求导致事件循环卡死。

**原因**：同步 `get_app_icon` 命令在 Tauri 主线程上阻塞，几十个并行调用卡死。

**解决**（后来整体移除）：后端 `static HashMap` 内存缓存 + 批量命令 `get_app_icons`。最终因图标匹配不可靠，整个功能移除。
